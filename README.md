```bash
python -m venv _work/venv
_work/venv/bin/pip install playwright pymupdf
_work/venv/bin/playwright install chromium

# देवनागरी फ़ॉन्ट (Chromium में एम्बेड होता है)
mkdir -p _work/fonts && cd _work/fonts
curl -sLo NotoSansDevanagari.ttf \
  "https://github.com/google/fonts/raw/main/ofl/notosansdevanagari/NotoSansDevanagari%5Bwdth%2Cwght%5D.ttf"
cd -

curl -sLo Kalam-Light.ttf   "https://github.com/google/fonts/raw/main/ofl/kalam/Kalam-Light.ttf"
curl -sLo Kalam-Regular.ttf "https://github.com/google/fonts/raw/main/ofl/kalam/Kalam-Regular.ttf"
curl -sLo Kalam-Bold.ttf    "https://github.com/google/fonts/raw/main/ofl/kalam/Kalam-Bold.ttf"
cd -

_work/venv/bin/python tools/render_hw.py       # हस्तलिखित शैली, सभी 13 अध्याय
_work/venv/bin/python tools/render.py          # आधुनिक शैली, सभी 13 अध्याय
_work/venv/bin/python tools/render_hw.py 5 9   # केवल अध्याय 5 व 9
```

| फ़ाइल | काम |
|---|---|
| `tools/content.py` | 13 अध्यायों की विषय-वस्तु — **दोनों शैलियों का एकमात्र स्रोत** |
| `tools/diagrams.py` | चार्ट, पिरामिड, प्लाज्मिड नक्शे (SVG) |
| `tools/render_hw.py` | **हस्तलिखित शैली** का लेआउट (Kalam फ़ॉन्ट) |
| `tools/diagrams_hw.py` | गुलाबी रेखा-चित्र — बीजाण्ड, नर व मादा जनन तंत्र, शुक्राणु, युग्मकजनन |
| `tools/content_hw.py` | हस्तलिखित शैली का ग्रिड लेआउट, परिचय व flow chart |
| `tools/render.py` | **आधुनिक शैली** का लेआउट (Noto Sans Devanagari) |
| `tools/notify_telegram.py` | Telegram पर प्रगति सूचना |

अध्याय ठीक एक A4 पृष्ठ में समाए, इसलिए कोई शीट कभी दो पृष्ठों में नहीं जाती।

## 📲 Telegram प्रगति सूचना

प्रत्येक अध्याय पूर्ण होने पर Telegram पर उसका चित्र और विवरण भेजता है।
टोकन कोड में नहीं रखा गया है — **एनवायरनमेंट वेरिएबल** से पढ़ा जाता है:

```bash
export TELEGRAM_BOT_TOKEN='<@BotFather से मिला टोकन>'
export TELEGRAM_CHAT_ID='<@userinfobot से मिला numeric id>'

_work/venv/bin/python tools/notify_telegram.py --test       # पहले टेस्ट संदेश
_work/venv/bin/python tools/notify_telegram.py --build-hw   # हस्तलिखित शैली + हर अध्याय पर सूचना
_work/venv/bin/python tools/notify_telegram.py --build      # आधुनिक शैली + हर अध्याय पर सूचना
```

वेरिएबल के नाम `BOT_TOKEN` / `ID` भी चलते हैं।

> अपने बॉट को एक बार `/start` भेजना आवश्यक है, वरना Telegram पहला संदेश रोक देता है।
